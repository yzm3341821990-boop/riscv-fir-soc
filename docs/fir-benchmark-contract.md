# 软件 / 硬件 FIR 周期对照 v1

标识 `fir-benchmark-cycles-v1`。本步保持 CPU、FIR、同步 RAM 和 MMIO RTL 不变，比较在同一 SoC 上运行的三份 C 固件。当前工作负载固定为 8 个样本、32 个抽头，数值沿用 `fir-q15-block-v1`。

## 共同条件

- 同一 C 源文件，分别编译 `software`、`hardware_cold`、`hardware_resident` 三种模式。
- 同一 Zig 0.13.0 / Clang 18.1.6、O1、ILP32、`generic_rv32+m` 和其余编译/链接参数；只允许 MUL，不支持其他 M 指令。
- 同一 CPU 版本和独立 1 KiB 指令 ROM / 1 KiB 双端口 RAM，固件代码仍不超过 512 字节。
- 每组数据的整个初始 RAM 镜像逐字节相同，包括零历史语义、输出初值和所有标志。输入与系数以 signed16 的 32 位符号扩展字存储。
- 软件允许跳过块首的零历史项；先做 signed32 乘法，再符号扩展到 signed64 累加，统一舍入和饱和，不写额外的累加器调试数组。
- 输入和系数为可变 RAM 数据，不强迫软件每次访问都使用 volatile；七组运行时镜像检查编译器没有把固定示例折叠成常量输出。标记及状态字段为 volatile，并使用编译器内存屏障固定计时边界。

## 固定 RAM 布局

| 字节地址 | 字段 |
| --- | --- |
| 512 | samples[8]，signed32 |
| 544 | coefficients[32]，signed32 |
| 672 | outputs[8]，signed32 |
| 704 | marker，0 → 1 → 2 |
| 708 | done |
| 712 | errors |
| 716 | polls |
| 720 | hw_cycles |
| 724 | hw_written |

字段由一个公共结构体和可核对的 ELF 符号固定；结束于 728，保留原 128 字节栈空间。三个固件的代码可以不同，数据初值与字段地址必须完全相同。

## 主指标：完整调用周期

所有模式在普通 CPU RAM 写入被接受的边沿写 marker=1，执行实际 FIR 函数调用，记录返回状态，随后写 marker=2。定义 `call_cycles = end_edge - begin_edge`，边沿来自真实 CPU 总线轨迹的周期计数。起始标记接受边沿不计入，结束标记所在指令时间计入；相同的边界和屏障策略用于全部模式。

- software：包括函数调用、输入/系数读取、乘加、舍入/饱和、全部输出写入及返回。
- hardware_cold：包括 ACK、全部 32 项系数配置、SRC/DST/COUNT、START、有限轮询、状态核对、函数返回。不能把已装载系数的调用冒充冷启动。
- hardware_resident：预先把 32 项系数装入硬件，之后才开始计时；区间仍包括 ACK、描述符、START、轮询和返回。这是明确的“系数已驻留”条件，不替代冷调用主指标。

每个固件仅执行一个任务，独立复位与 RAM 装载。驻留模式的预配置成本在主区间外单独保留证据；当前并未宣称运行过连续任务的长期吞吐。

输出数值由相同的独立数值模型在计时后检查；两条路径均不把额外 C 数组自检或原始累加器调试写入计时区间。硬件 CYCLES/WRITTEN 的诊断读取也放在结束标记之后。

## 次级指标与等待条件

无额外 DMA 等待是主对照。另运行确定性的 RAM B 端口等待场景：整个仿真时钟的周期号 mod 7 为 0、1、2 时暂停接受，其余接受。该策略的相位由实际启动时刻决定，报告每个用例的真实周期；软件不使用 B 端口。

硬件内部 CYCLES 单独报告，它从 START 到最后一个写入被接受，包含清历史、DMA、MAC 和等待，不包含 CPU 配置和结束检测，不能用作完整调用加速比的分母。

每组数据报告 `software_call_cycles / hardware_call_cycles`，分别给出冷调用和系数驻留调用。比值小于 1 也保留。七组基准、冲激、半格、正负极值、零输入和零系数均报告，不只选择最好结果。

## 检查与证据

必须核对完整 CPU 提交、真实 CPU/DMA 请求、全部最终 RAM 与寄存器以及精确输出。软件使用独立 ISA 模型；硬件重放包含 MMIO/DMA 状态的事务参考。计时标记必须唯一、有序、整字写入；冷/驻留系数配置窗口、最终 DMA 写入和 CPU 读到完成状态的位置均须核对。

对错误输出、缺失/重复/反向标记、将系数装载移出冷调用、过早结束和省略完成轮询等情况做受控负例。超时、错误状态或不一致的初值/布局不得产生有效性能结果。

报告绑定 RTL、固件、工具、输入与验证源码哈希，保留逐组结果、CSV 和可重新运行的 ModelSim 入口。编译产物在两个独立目录中核对复现。

这里只测量功能仿真的时钟周期比。测试时钟不代表可实现 FPGA 主频；综合、DSP/逻辑占用、静态时序、真实耗时、能耗与上板加速均不在本步证明范围内。
