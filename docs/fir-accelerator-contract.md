# 串行 FIR 核接口 v1

标识 `fir-serial-stream-v1`，数值沿用 [fir-q15-block-v1](numeric-contract.md)。本步只实现运算核，尚未接 CPU、MMIO 或共享 RAM。

## 时钟与事务

单一 `clk` 上升沿；`rst` 高有效同步复位。所有数据与控制属于该时钟域。ready/valid 同为 1 且 rst=0 的边沿接受一次事务。数据仅在事务时有意义；发送者等待时须保持 valid 和数据，接收者可以无限期暂停。

| 端口 | 宽度 | 意义 |
| --- | --- | --- |
| clear_valid / clear_ready | 1 / 1 | 清空历史，保留系数 |
| cfg_valid / cfg_ready | 1 / 1 | 写一个系数 |
| cfg_addr / cfg_data | 5 / signed16 | H[0]～H[31] 地址及数值 |
| s_valid / s_ready / s_data | 1 / 1 / signed16 | 输入样本 |
| m_valid / m_ready / m_data | 1 / 1 / signed16 | 舍入、饱和后的输出 |
| m_acc | signed40 | 与 m_data 同一事务的舍入前累加值 |
| busy | 1 | 已接受输入，正在运算或等待输出被接收 |

空闲时优先级为 clear > cfg > sample。clear_ready=1；cfg_ready 在 clear_valid=0 时为 1；s_ready 在 clear_valid=cfg_valid=0 时为 1。一次边沿最多接受其中一种操作。忙时以上三个 ready 均为 0，不能修改系数或历史；控制请求若要等待，必须保持 valid 到真正握手，不能把未握手的单拍脉冲视为接受。

复位时三个 ready 及 m_valid 均屏蔽为 0；复位边沿取消所有在途事务，清零系数、历史、累加器及输出寄存器。复位释放后处于空闲。输出已经被接收的事务不撤回；被取消的输入不再产生输出。复位不代表外部 RAM 自动清零。

## 延迟与状态

状态为 IDLE → MAC → HOLD_OUTPUT → IDLE。样本在边沿 E0 接受并移入 32 项历史，H[0] 对应刚接受的样本。E1～E32 各计算一项有符号 16×16 乘积，符号扩展至 40 位后相加；E32 的最后一个乘积必须包含在输出中。E32 后 m_valid=1，m_data、m_acc 同时有效。

最早 E33 接收结果，E34 接受下个输入；无间隙、无暂停时输入间隔 34 拍。结果暂停时 m_valid、m_data、m_acc 保持稳定，busy 保持 1，不能接收下个样本。没有输入/输出 FIFO，也不支持同一边沿消费旧结果并接受新输入。

系数写和 clear 各占一个接受边沿。clear 清空历史及工作/输出寄存器，保留全部系数；不自动输出卷积尾部。连续样本保留历史；独立块之间显式 clear。空块对应 clear 后没有输入事务，产生零个输出。系数写本身不清历史，换系数后若要开始独立块必须 clear。

这是固定 32 抽头的教学基线，未参数化。一次样本始终执行 32 次 MAC，即使系数或历史为零。串行复用的 RTL 表达式只含一个 16×16 乘法；是否映射到 DSP、寄存器或 RAM、主频和资源数量必须以综合报告确认。10 ns 测试时钟仅为功能仿真时间尺度。

## 验证边界

检查每个输出的 signed16 结果和完整 signed40 累加值、32 拍延迟、输出暂停稳定性、无重复/漏结果、输入间隙、控制优先级、清历史保留系数、忙时控制请求不被接受、复位取消 MAC/待接收输出以及复位清系数。长块和仅 H[31] 非零的用例覆盖最远历史项。原 13 组向量保持不变，另对照七组已编译 C FIR 的实际执行结果。

本核的周期数不包含 CPU 配置、共享 RAM 读写、轮询、同步或驱动开销，不能据此报告系统加速比。MMIO 非法地址、重复 START、DMA 等规则属于下一层包装器。
