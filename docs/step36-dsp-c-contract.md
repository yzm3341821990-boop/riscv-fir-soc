# Step36 DSP C platform contract

Separate candidate: `DSP6`, identity `44535036`, ABI `00360001`. Existing CPU5 and LIV0 projects and SOFs remain frozen. DE2-115 EP4CE115F29C7, 50 MHz input / 25 MHz core, original 66 pins and 2.5 V bank settings. User compiles and programs; preparation/simulation never access hardware.

CPU5's complete RV32IM core, 16 KiB uploaded instructions, 32 KiB high-alias data RAM, timer, mailbox and C ABI are retained in separate DSP entities. Only aligned LW/SW access is admitted to FIR `0x40003000..0x40003fff` and profiling marker `0x40004000`. Byte/halfword peripheral instructions trap. Other previously invalid addresses still trap.

The existing four-lane 32-tap FIR uses signed Q15 inputs/coefficients, signed 40-bit accumulation, round half away from zero and saturate to signed16. Registers: CMD +0 (1 start, 2 acknowledge), STATUS +4 (busy1/done2/error4), physical source +8, destination +12, count +16 (1..4096), accelerator elapsed +20, written +24, error +28, coefficient bank +256..380. Source/destination are aligned low physical RAM byte addresses, nonoverlapping, within 32 KiB. C high pointers are explicitly translated. All 32 coefficients must be loaded before first start. START clears FIR history; streaming explicitly prepends 31 prior input samples. Polls are bounded and errors prevent successful completion.

Shared RAM CPU port A has priority over conflicting DMA port B; B advances only on request AND ready. Both reads have registered acceptance and old-data semantics. CPU reset / new job resets FIR, configuration, profiling and DMA state. Host RAM access is blocked during execution. A C task may return success only after DMA completion and full output comparison.

Marker stores: 1/2/3 begin software/cold/resident interval; 0 ends active interval. Boundaries are accepted full-word CPU stores. Three 64-bit accumulators sum all intervals; three counters count completed intervals. Nested starts, unmatched ends, other values set a sticky error. Status pages 13..15 return each accumulator low/high, completed intervals, active ID and error. No expected cycle table enters RTL.

First application generates a deterministic 1 kHz + 11 kHz signal locally from a fixed 48-sample integer table; accepts N=1..262144. It processes 225 new samples per block, with 31 explicit history samples and zero-padded tail. Each block runs CPU C, cold FIR (including coefficients) and resident FIR, compares every one of the 256 outputs, and accumulates a checksum over valid samples only. Generation and verification lie outside the three intervals. It retains the last valid output window in ordinary RAM for readback. Long signals require one code/data upload and one final readback; there is no per-block JTAG exchange. Stop is bounded by the watchdog; board reset remains a user operation.

Evidence boundaries: scalar preflight predicts functional results but never clock cycles; actual RTL verification checks commits, CPU requests, every accepted DMA word, complete final RAM and all registers. Independent integer convolution checks the final checksum and window. Mutation checks must reject corrupted FIR output, incorrect marker counting and wrong peripheral decode. Quartus resources/timing and physical performance remain unknown until user compilation and board observation. GitHub update follows this upgrade's verified delivery; no license is chosen automatically.
