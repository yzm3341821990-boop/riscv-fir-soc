# RegisterFile32 契约

标识：`regfile32-rv32i-v1`。实现语言为 VHDL-93。

## 外部接口

| 信号 | 方向/宽度 | 含义 |
| --- | --- | --- |
| clk | 输入，1 位 | 所有写入和复位均在上升沿采样 |
| rst | 输入，1 位 | 高有效同步复位 |
| we | 输入，1 位 | 写使能 |
| waddr | 输入，5 位 | 写地址，0～31 |
| wdata | 输入，32 位 | 写数据 |
| raddr1/raddr2 | 输入，各 5 位 | 两个独立读地址 |
| rdata1/rdata2 | 输出，各 32 位 | 两个独立组合读结果 |

寄存器为 x0～x31。x0 两个读口始终返回零，向 x0 写入被忽略。x1～x31 可以存储任意 32 位模式。

## 时序与优先级

1. 上升沿 rst=1：x1～x31 全部清零，即使此时 we=1。
2. 上升沿 rst=0、we=1、waddr≠0：仅更新该地址。
3. 其他情况保持所有寄存器。
4. 读口异步跟随读地址和已保存的寄存器内容；不依赖下一个时钟沿。
5. 同址读写：上升沿前读到旧值，沿后读到新值，不提供写入前的组合旁路。
6. rst 在两个上升沿之间拉高不会立即清除寄存器；要等下一个有效上升沿。

普通寄存器上电内容不作承诺。测试在第一个有效复位沿后才检查 x1～x31 的内容；x0 在复位前也返回零。接口契约针对 0/1 二进制输入，不把 U/X/Z 当作合法地址或控制信号。

仿真遇到含 U/X/Z 等未知值的读地址时，输出全 X，避免把未知地址经 `to_integer` 当作零地址。此处理用于暴露启动阶段尚未稳定的连接，不代表 FPGA 能检测物理未知电平。寄存器内容仍不做声明初始化；合法地址的读写语义不变。

未来流水线在同一个沿写回并采样译码操作数时，需要按流水线时序明确安排旁路；本模块的沿前/沿后语义不能被当作自动解决全部冒险的保证。

## 本轮验证

使用 10 ns 的测试周期，每周期在下降阶段施加输入，4 ns 后检查旧状态；5 ns 时产生上升沿，沿后 1 ns 再检查新状态。每周期两个读口各检查两次，共四次结果比较。时间间隔是仿真激励安排，不代表已验证的 FPGA 时钟频率或读延迟。

覆盖首次复位、x0 写入忽略、x31、逐地址写入、全部 32×32 读地址组合、写使能保持、覆盖写入、同址读写、中途复位与复位优先级，以及固定种子随机序列。

两项独立故障注入分别把写边沿改为下降沿、使复位在 we=1 时失效；要求编译成功后由结果断言拒绝，并非零退出。源码副本仅放在构建目录，正式 RTL 不保留故障修改。
