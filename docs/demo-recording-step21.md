# 当前 step21 演示录制清单

用户负责录制；当前还没有收到视频。本清单供补充展示使用，不要求为整理文档重新编译。

建议一段 60～90 秒视频，保留正常速度的连续操作：

1. 拍到 DE2-115 板名和正常运行的 LED。旁白说明：自设计五级 CPU 运行 C，经 MMIO 调用四路 FIR。
2. 镜头同时覆盖 SW3..SW0 和数码管，先选择 0110、0111、1000，分别展示 1024 点软件、冷调用、驻留的真实显示。每个位置停留约 3 秒。
3. 如时间允许，依次拍编号 0～5，展示 64/256 点三种模式。用[九组对照](step21-board-benchmark-guide.md)解释，不把对照表编辑进屏幕当作实物读数。
4. 按住 KEY0，拍到清状态；松开后拍九组自动重跑以及通过 LED 状态。该片段单独记录是否实际拍到。
5. 如同时录电脑屏幕，可展示真实 Programmer 文件名/结果与当前 SOF 哈希，以及 Quartus 的资源和时序报告。

解说示例：

> CPU、硬件 FIR 使用同一份数据和定点舍入规则。冷调用包含系数配置；驻留模式事先配置系数。数码管由开始、结束标记之间的实际计数驱动。这里展示的是本项目 CPU/C 基线与专用 FIR 的比较。

原始视频回来后，按 selector、实际 hex、拍摄时间位置、是否完成 KEY0 重跑记录。当前[空白数字模板](../reports/step21-board-benchmark/board-measurement-template.csv)仍保留，已有[用户概括反馈](../reports/step21-board-benchmark/board-observation.json)另列。未拍到的项目留空；外部仪器计时和长期实时音频不在本次展示范围。
