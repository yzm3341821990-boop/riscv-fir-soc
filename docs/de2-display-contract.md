# DE2-115 结果与周期显示 v1

本版单独生成 `de2_115_display` 工程，保留已由用户确认 LED/KEY0 行为的第一版工程及源码。CPU、共享 RAM、FIR、C 固件和 25 MHz 时钟不变。

- SW[2:0] 按二进制选择输出 0～7；SW[3]=0 时 HEX7..HEX0 显示该输出实际 DMA 写回的完整 32 位字，不从期望值 ROM 生成显示数据。
- SW[3]=1 时显示程序周期数：从 RAM 装载完成后 CPU 获释的第一个系统时钟边沿，到板级监控检测程序末尾的边沿，首尾均计数。包含 C 配置、轮询、FIR 工作、结果检查及终止监测；排除初值装载。它不同于 FIR 内核 CYCLES，也不同于第十四步完整调用标记区间。
- HEX0 是最低四位，HEX7 是最高四位。7 段低电平点亮；位 0～6 对应 a～g。显示十六进制，负数为 32 位二进制补码。
- 上电、KEY0 复位和运行中显示空白；自检通过后才能显示结果。出错或超时显示 EEEEEEEE。旧 LEDR0/1/2/3 的完成/通过/错误/心跳含义保持。
- 输出快照、周期数和错误均在 KEY0 时清除，下一次启动重新获取。完成后周期数与结果保持，拨动开关不得改变 CPU/FIR 执行或计数。
- 4 路异步开关各经过两级寄存器；仅用于观察选择，开关切换期间允许短暂显示中间选择。它们不是用于发起交易的多位命令总线。异步路径仅排除到第一级寄存器，级间路径仍分析。
- 根据官方手册表 4-1/4-4/4-8 和实物照片，参考 JP7=2.5 V、JP6=3.3 V。数码管跨多个 I/O 电压组，逐引脚指定电压。引脚依据官方手册，不以旧板型引脚替代。

本版先完成 RTL 仿真、故障注入、综合和时序检查。第一版 LED 自检的用户反馈不能作为新增数码管功能的实物验证。

来源：[Terasic 官方手册](https://www.terasic.com.tw/attachment/archive/502/DE2_115_User_manual.pdf)，印刷页 35～38、41。
