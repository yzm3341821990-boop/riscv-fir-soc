# 单镜像板级成对计时契约

标识 `board-fir-benchmark-v1`，step21。沿用 step20 r1 的五级 CPU、MUL、32 KiB M9K、四路 FIR、数据、编译器和固件。新范围是板级执行编排和完整调用计数，不改指令语义或 FIR 算术。

单个 bitstream 顺序执行九个配置，顺序为 N=64、256、1024，各长度依次软件、冷调用、系数驻留。每个配置有独立程序 ROM bank；每种长度的一份初始 RAM 在三个模式间逐字相同。切换配置时保持 CPU/FIR 复位并重新装载全部 8192 个 RAM 字。KEY0 重新执行九组。

计数器只从 CPU 真正接受的 `marker=1` 全字写入沿计到同一地址 `marker=2` 的接受沿，保存两沿间隔。包含该区间内的 CPU 暂停、访存、配置、计算、轮询与返回开销，排除初值装载、区间后的 C 结果检查以及 hw_cycles/hw_written 诊断读取。驻留模式的系数装载位于区间外，仍由仿真监测核对。开始前为零，结束后冻结；重复/乱序标记和计数溢出报错，复位取消未完成测量。

所有九次 C 程序均须核对全部 N 个输出、写入 done、返回正常并提交到相应终止 PC。软件结果必须来自 CPU 的实际 RAM 写入，硬件结果来自接受的 DMA 写入；检查地址、数量及前八个数值。任一配置失败都置错误显示，不把部分完成当成整套通过。

可综合 RTL 中不得包含期望周期表、软件/硬件比值常数或以预期值覆盖计数结果。期望周期只放在 testbench、报告与运行说明。验证监测器从外部 50 MHz 输入时钟独立计数，并在核心接受沿之前采样 CPU 请求，核对每组实际标记间隔与显示值。

九组通过后，SW[3:0] 作为完整选择编号 0..8，分别显示九个实际完整调用计数。编号 9..15 显示空白；任意故障显示 EEEEEEEE。正常 LEDR0/1 亮、LEDR2 灭、LEDR3 闪；自检进行中数码管为空白。这里的 SW3 不再单独表示“周期模式”，本工程专门用于成对计时，原 step20 显示/镜像保持可用。

Quartus 全编译与板卡操作由用户完成。功能仿真通过不能记成新 bitstream 已编译或已上板；用户报告的读数与视频、独立仪器测量分别归档。GitHub 新版本发布仍需明确授权。
