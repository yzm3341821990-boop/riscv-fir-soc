# 录视频照着这一页操作

目标：用一段连续画面展示 CPU＋FIR 的实际结果选择、程序周期和按键重跑。建议 45～60 秒；如果把八个输出全部拍齐，可以录到 60～90 秒。

## 开录前

- 下载当前 display 版本，保持开发板通电。
- 找到 SW0、SW1、SW2、SW3、KEY0，以及 LEDR0～3。
- 镜头尽量同时拍清数码管和正在拨动的开关，避开保护板反光，先对焦。
- 确认自己能读到第一项 `00002000`；出现不同结果时先记录实际画面，不按预期数字配音。

## 最短完整拍摄顺序

| 时间参考 | 动作 | 应拍清的画面 |
| --- | --- | --- |
| 0～8 秒 | 拍整板与标识，SW0～SW3 全为 0 | DE2-115、00002000、正常状态灯 |
| 8～15 秒 | 只把 SW0 拨到 1 | 00003000 |
| 15～23 秒 | SW0=0，SW1=1，SW2=0，SW3=0 | FFFFA800，展示负数补码 |
| 23～33 秒 | SW3=1 | 0000046B，十进制 1131 个程序周期 |
| 33～43 秒 | 按住 KEY0 约半秒后松开 | 按住时空白，松开后恢复；状态灯正常 |
| 43～50 秒 | SW0～SW3 恢复为 0 | 再次显示 00002000，心跳灯持续闪烁 |

KEY0 是四个黑色小按键中标着 KEY0 的那个。红色按钮是电源，录复位重跑时使用 KEY0。程序执行很快，松开后几乎立即恢复属于正常现象。

LEDR0/1 正常为常亮，LEDR2 为灭，LEDR3 缓慢闪烁。相机可能无法在某一静态帧体现闪烁，给心跳灯留几秒连续画面。

## 如果想一次拍齐验收

保持 SW3=0，把 SW2..SW0 依次拨成以下八种，每项停约两秒：

| SW2 SW1 SW0 | 预期显示 |
| --- | --- |
| 000 | 00002000 |
| 001 | 00003000 |
| 010 | FFFFA800 |
| 011 | 00004400 |
| 100 | FFFFD000 |
| 101 | 00003C00 |
| 110 | FFFFE200 |
| 111 | FFFFF800 |

然后拍周期模式和 KEY0 重跑即可。七段显示的 b、d 为小写字形，不要求它们像印刷体大写字母。

## 可直接使用的简短解说

> 这是在 DE2-115 上运行的自设计多周期 RISC-V CPU 和 32 抽头定点 FIR 加速器。CPU 执行裸机 C 程序，配置并启动 FIR，检查硬件写回的结果。拨码开关可以切换输出数据；SW3 切换到整段自检程序的周期数。按 KEY0 会重新装载数据并运行自检。

1131 拍是当前整段自检程序的预期计数，包含配置、等待和检查。不要把它称为 FIR 单独计算周期，也不要把仿真对照的 2.224×/5.214×直接配成板上实测加速比。
